Astral python-build-standalone distribution, Windows x86-64, build 20261021:
https://github.com/astral-sh/python-build-standalone/releases/tag/20261021
The Python license is in runtime/LICENSE.txt and each scientific runtime.
Provider and library notices are in third-party-licenses/python. The provider's
complete corresponding build-source archive is in third-party-sources.
OpenT1D removes regenerable bytecode and pip from the private runtime copies,
installs the declared locked distributions, and adds one source path .pth file.
No operating-system Python installation is changed.

Python distributions are retained in their separate locked environments:
- runtime/Lib/site-packages: repository tooling and graphical workflow runtime
- runtimes/native/Lib/site-packages: maintained simglucose scientific runtime
- runtimes/observer/Lib/site-packages: beta-cell observer scientific runtime
Each distribution's metadata, copyright and license files remain beside it.
package-manifest.json records all versions, source hashes, and installed bytes.
