## Acceptance chosen before outputs

1. Build a noneditable SDK, install it in a fresh SDK-only environment and launch
   the GUI from an unrelated directory. Verify every new static asset's manifest
   binding and passive project opening/restart without a ledger mutation.
2. Use one project across GUI and Python/CLI: freeze MMTT, run it, freeze fasting
   and derive parent-linked 15 g, execute the native task and explicitly
   reconstruct reports. Compare returned plan/attempt IDs and scientific
   configuration with the existing services; do not equate GUI transport IDs
   with ledger identities or invent native phase percentages.
3. Retain a real failed or interrupted attempt, retry explicitly, and keep the
   planned denominator. Distinguish an input-validation refusal from registered
   failed execution, complete calculation from interpretation, and report
   verification from a new simulation.
4. Relocate the entire project through the GUI and reopen it with the installed
   SDK. Require exact JSON/Markdown/SVG report bytes with original inputs/source/
   runtime locations unavailable. Old complete projects remain readable; an old
   artifact's execution attachment is refused until explicitly reattached.
5. Exercise actual Cancel and server shutdown with a live owned run, empty
   observed cleanup and an unrelated process preserved. Metadata/read actions
   drain; SIGKILL remains an unobserved crash. Reject duplicate mutations.
6. Refuse missing/stale tokens, foreign/missing mutation Origin, rebinding Host,
   duplicate headers, transfer encoding, oversized/nonfinite/duplicate-key JSON,
   linked/special paths, unsafe output nesting and changed report bytes. Never
   execute an archived callback or serve arbitrary local files.
7. Inspect real browser behavior, keyboard operation and a narrow viewport.
   Prepare a candidate-bound packet with neutral participant tasks, separate
   facilitator expectations and blank observations. Mark all actual human
   sessions and independent assessment unrun until they exist.
8. One owner runs `uv sync --locked` and
   `uv run --locked python scripts/check.py` on the final clean revision. Retain
   local, browser, native and hosted evidence separately under ignored
   `results/ot065-thin-gui/`, including failures and exact source/artifact hashes.
