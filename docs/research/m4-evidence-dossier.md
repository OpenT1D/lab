# M4 evidence dossier: a bounded secretion reference

Reviewed on 20 September 2026 for OT-024 and the first OT-025 experiment. The question is: **can a supplied, declining post-bolus glucose profile be transformed into a reproducible calculation of glucose-evoked insulin secretion using a fully identified published equation set?** This is a software and numerical question. It does not ask whether a treatment restores beta cells or whether the calculation predicts a person with T1D.

The selected reference is the two-state IVGTT reduction in Pedersen and Cobelli (2013). [The protocol](m4-protocol.md) fixes the experiment before implementation. [The model card](models/pedersen-cobelli2013.md) is the canonical specification; [the coupling proposal](m4-coupling.md) identifies work still required for OT-026. Functional capacity, anatomical cell number, measured C-peptide and insulin independence are different quantities.

## Bounded search and candidate comparison

The search followed original minimal-secretion, granule-pool and C-peptide-kinetics publications and the Pedersen author-code index. Search terms included glucose-dependent insulin secretion, oral/IVGTT minimal model, beta-cell capacity, C-peptide kinetics, author code and the selected DOI with correction/erratum. This was targeted feasibility work, not a systematic review. No correction was found in the inspected publication records and targeted search; absence of a search hit does not establish that no correction exists.

## Source audit changes the claim

The [author's publication index](https://www.dei.unipd.it/~pedersen/pub.html) links [secr_model_IVGTT_new.ode](https://www.dei.unipd.it/~pedersen/secr_model_IVGTT_new.ode). It references a glucose data file not supplied in the inspected package and offers an exponential surrogate. A header-only availability check for `gluXPP_IVGTT.dat` in the same public author directory returned HTTP 404; this does not exclude another source location. The published cohort input was not recovered as a licensed, versioned dataset. The implementation uses a declared synthetic stimulus.

Three discrepancies prevent describing the output as an exact reproduction of Figure 2b:

1. **Initialization:** published equation 4.13 contains the denominator `p_minus + f`, while the author file explicitly sets `X(0)=92.7`. With the protocol's `G_b=5`, `G_max=17.2` and basal equilibrium, the literal formula gives approximately `0.15465 microgram`. Neither this difference nor the difference between the paper's basal convention and the author's `glu0=4.9127222` is silently repaired. The alternative initialization is only a sensitivity case, not an author-approved correction.
2. **Reduction:** differentiating the product defined by equation 4.10 produces a glucose-derivative term omitted by equation 4.11b. OpenT1D implements the stated reduced equations, without claiming exact equivalence to the full granule model. This mathematical observation was made during this audit; no author endorsement is claimed.
3. **Output meaning:** equation 4.11c outputs the evoked component. The basal term present in the full model's equation 3.7 is absent. Adding an assumed basal rate would change the specification. Neither portal transit nor systemic clearance is represented by these two states.

The paper's approximately 12-minute delay and Figure 2c/d functional relationships supply published targets that do not require patient trajectories. An independently calculated constant-input solution and numerical convergence assess code correctness. None supplies empirical validity for the synthetic trajectory.

The author file was inspected for provenance, not copied into the software or redistributed. No explicit source-code license was found in that file or its index. The article's PMC record states that rights are reserved. Public access is not a redistribution grant. Original OpenT1D code implements the attributed mathematical specification; downloaded sources remain in ignored local results.

## Prediction, reconstruction and identifiability

A glucose-driven secretion model predicts release conditional on its fixed parameters and glucose input. C-peptide deconvolution infers release from measured C-peptide through a kinetic model. A forward C-peptide model predicts concentrations from release. Those are three distinct operations; agreement among them after fitting the same observations is not independent validation.

There are no human measurements in this experiment. Consequently no human parameter estimates, confidence intervals or identifiability results are reported. Functional capacity is a dimensionless multiplier of an already specified reference output. With both that multiplier and a free common scale on the model's `c`, `M0` and initial pool, identical outputs can be constructed: scale those quantities by a positive factor and divide capacity by it. This is an explicit structural ambiguity, not just a shortage of samples. Separately, `p_plus*f/(p_minus+f)` enters the reduced dynamics as a combined parameter, so secretion-only observations do not distinguish all three component rates.

Useful future estimation must fix or constrain such combinations using independent information. Dense early and later secretion-related observations are needed to separate initial release from delayed replenishment. Sparse glucose/C-peptide endpoints can support an integrated response while failing to identify the dynamic states. CGM alone is insufficient to distinguish secretion, exogenous insulin, clearance, insulin action and meal absorption. Synthetic recovery, if later attempted, must remain separate from claims about noisy human measurements.

No request, contact or patient download occurred.

Minimum useful future measurements are paired laboratory glucose and C-peptide with actual sample times, assay units/detection limits, fasting baseline, stimulus dose and delivery timing, early and late samples, kidney function and demographic variables needed for the selected kinetic reference. Insulin concentration, exogenous formulation/dose/route/timing and body size are required for later metabolism coupling. For graft work add graft location, transplant dates/repeated infusions, product or islet-equivalent information, immunosuppression and contemporaneous metabolic outcomes. These are requirements, not claims that each candidate dataset contains them.

## Feasibility verdict and review needs

OT-024 supports a bounded standalone reference now. Empirical T1D assessment, source-initialization reconciliation, physiological basal secretion and transplantation interpretation remain open. OT-026 must first resolve those issues and verify the explicit metabolic input in the [coupling proposal](m4-coupling.md). M4's complete coupled acceptance criteria are not met by this experiment.

Review is needed from a secretion-model specialist, a C-peptide assay/kinetics specialist, a T1D/islet-transplant clinician and a statistician experienced in identifiability. The [unsent collaboration brief](m4-collaboration-brief.md) asks concrete questions and defines potential measurement access without claiming a partnership. A later M5 question could ask whether independently measured graft function predicts subsequent metabolic burden, but choosing follow-up windows, confounders, endpoints and an independent assessment cohort belongs to OT-027. A scalar capacity adjustment is not a treatment mechanism.

## BC-006 source reconciliation follow-up

The [executed BC-006 audit](m4-source-audit-results.md) preserves the discrepancies above but narrows their interpretation. Whole-pancreas intent, a separate coded basal rate and an extra C-peptide observation multiplier are now explicitly traced. The pre-bolus pool at the author seed predicts 92.739536 micrograms, consistent with 92.7 at the printed precision; the source warmup state and reduced-model convention remain unconfirmed. Independent numerical checks quantify initialization effects and the product-rule omission. No historical implementation, population calibration or evidence status is silently changed. The remaining questions are collected in the [focused review packet](m4-collaboration-brief.md#source-reconciliation-review-packet).
