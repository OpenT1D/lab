## Cancellation, unsealed evidence and refusals

Two real service/browser cancellations of an explicitly slow self-authored
synthetic predictor retained the first interrupted participant and second
unattempted participant, with all 1,718 planned origins. Native cooperative
shutdown sealed readable partial reports: execution is cancelled, saved analysis
is verified and complete cohort is false. The actual browser cancel button and
shared busy gate were exercised, rather than inferred from a mock response.

A separate self-authored process-failure fixture killed only its own live native
coordinator through direct process ancestry. It did not use an archived PID or
target an unrelated process. This produced a genuinely unsealed archive with
nine files and 299,748 bytes. The GUI retained its raw archive, prepared synthetic
bytes and original execution logs outside the worktree with separate receipt
`opent1d.m3-forensic-retention/1`. No native report or verified package is claimed.
After original paths became unavailable, the retained raw inventory still agrees.

Thirty observed process/start identities over the two cancellations and native
owner-death case were rechecked after termination: no matching observed process
survived, no forced cleanup was recorded and no remaining owned processes were
reported. This covers observed live descendants on macOS; it does not guarantee
cleanup after an uncatchable server kill or for unobserved forks. The M3 nested
grace is 20 seconds within the GUI's 30-second outer grace.

The independent CLI acceptance records eleven actual refusals: tampered and
additional package bytes, symbolic/hard links, unsafe manifest paths, existing
and overlapping output, incompatible or dirty readers, a constructed unsealed
negative fixture and the actual unsealed GUI owner-death archive. The final
ordinary-export refusal left no package or staging directory, preserved source
bytes and granted no integrity/reconstruction/completeness result. GUI paths,
opaque IDs, changed readiness and transport/session boundaries also have focused
regression checks. Any present original M3 report must match authoritative
reader evidence at export.

Two early GUI-service negative fixtures had a shortened configuration roster
that disagreed with the original observation schedule. The native runner rejected
them at input before predictor execution; they are retained as input-validation
diagnostics and are excluded from predictor-failure/cancellation claims. Corrected
failure/cancellation fixtures preserve the complete native observation schedule.
All failed, cancelled and unsealed GUI acceptance runs have independent raw copies.
