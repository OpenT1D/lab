# 0087 — Reproducible comparisons of frozen plans and variants

Date: 31 October 2026. Status: selected for implementation.

## Decision

Implement roadmap step 4 through the installed SDK and shared project ledger.
Freeze an ordered roster of 2–16 labelled members, each naming an existing plan
and a task-owned selector, an explicit baseline and a research question. A member
selects an MMTT assumption variant, a sampling schedule/variant, or a supported
installed M4 source/load. Plans may be shared by several members. Refuse plans
with prior attempts: the complete roster must precede execution. Derive a fresh
plan to repeat previously executed assumptions. The first attempt of each plan
is the comparison's fixed attempt; later retries remain history and cannot hide
its original failure. Existing sequential execution and project leases own runs.

Persist the comparison as an immutable ledger event. Reconstruct a sealed report
against an explicit ledger prefix/tip, retaining every member and planned case,
including unattempted, unfinished, forensic, failed and incomplete results.
Reusing that prefix must reproduce the saved report after later runs or retries.
Verify selected native evidence through its existing trusted reconstruction
reader; never execute archived Python or supplied native models. MMTT's existing
offline reader may repeat its verification arithmetic. Bind the separate
comparison adapter/renderer identity without changing native source inventories.

## Scientific conventions

Compare within one admitted task, reader, protocol and source/runtime identity.
MMTT comparisons require identical original participant metadata, observation
bytes and visit order. Retain whole-body secretion including basal over 0–120
minutes, in pmol, with follow-up minus baseline. Show participant allocation,
point availability, conditional interval completeness and direction separately.
An unresolved interval is not evidence of no change. Sampling keeps its explicit
development evidence, allocation and preselected schedule rationale; no evaluation
result selects a schedule. A changed supported schedule is an explicit contrast.

Installed M4 retains the reviewed two-source boundary and supported initial
gastric-load scenarios. Compare accepted candidate trajectories over the complete
0–240-minute quarter-minute grid, separately for glucose (mg/dL), insulin and
C-peptide (pmol/L), reusing its native descriptive contrast calculation. Whole
source, common-reference/control, observer, repeat and numerical acceptance remain
required. A partial successful prefix supplies no accepted contrast. Different
loads are declared initial conditions, not timed meals. There is no common score
between secretion amounts and concentration trajectories.

Show explicit changed scientific fields and selector changes relative to the
baseline. Missing values remain null with reasons; no intersection-only roster,
imputation, zero substitution, pooled allocation, efficacy ranking or new
uncertainty/equivalence claim is selected. Native protocols, numerical files,
frozen baselines/tolerances and OT-059 fixtures remain unchanged.

The [implementation record](../research/workbench-comparisons.md) owns acceptance,
counterexamples, review, final local evidence and remaining qualification gates.
