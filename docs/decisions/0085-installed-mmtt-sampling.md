# 0085 — Preserve the sampling study through installed project services

Date: 30 October 2026. Status: accepted for bounded implementation; verification pending.

## Decision

Add `mmtt-sampling` to the installed SDK and shared project workbench under
roadmap step 2. Reuse the unchanged OT-055 freeze, masking, execution, estimator
and trusted reconstruction. Capture four explicit raw files (package, CSV,
settings and design) plus a sealed development-only import. Keep original bytes,
the native frozen study, ancestry, both protocols and complete attempt history.
Do not extend or regenerate the frozen OT-059 version-1 packet.

Use a separate sampling service adapter. Its planned slots identify schedule,
participant and assumption; retain unattempted and failed cells. Admission checks
native parent/child associations and saved draw evidence; explicit trusted
reconstruction remains the arithmetic check. Never execute archived snapshots.
Return hashes for the parent and every available child report so relocation
and the workbench retain native report links and complete evidence.

Version the installed capability descriptor as `opent1d.installed-sdk/3` with
the sampling task. Keep strict version-1/version-2 capability validation and
legacy task readers; do not relabel old artifacts or broaden native runtime
permission. Runtime attachments remain bound to the actual application.

The workbench calls the same SDK for supplied sampling controls. Serve only
verified report names, including bounded `studies/<schedule>/report.md` and
`.json` children; nested paths never authorize arbitrary file access or dynamic
download headers. Detect changed nested report copies before serving them.

## Preserved scope and acceptance

Keep 0–120-minute whole-body secretion including basal, follow-up minus baseline,
fixed kinetics, shared perturbations, actual-time masking, participant allocation
and development-only schedule selection. Do not change estimator code, frozen
protocols, baselines or tolerances. No human-data intake, schedule optimization,
general editable workbench, reader migration or new public app capability is added.

The [selected task record](../research/installed-mmtt-sampling.md) owns installed
CLI/Python/GUI parity, complete/incomplete/cancelled evidence, rejection cases,
relocation, browser observations, separate review and final repository checks.
This interface decision supplies no numerical result or independent user evidence.
