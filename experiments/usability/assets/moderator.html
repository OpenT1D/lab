Moderator instructions

Plan 45–60 minutes; record longer setup or execution separately. Read the goals, not a click sequence. Record every intervention and the participant's own explanation.

Record each task as completed without help, completed with help, blocked or not assessed. An unobserved task is not a success. If execution is blocked, record it before using a saved report.

Reference reports

The complete and interrupted synthetic M4 archives are registered in Added archives with session-reference tags. Open the experiment interface to explicitly check their saved analysis before reading them. Full planned denominators and unavailable values remain visible.

After the session

Export the observation form to a private location outside scientific archives. Preserve the original record. Prioritize blocking and interpretation issues; repeat affected tasks with the participant on an identified fix. A novice session does not automatically complete intended-researcher or P1 acceptance.
